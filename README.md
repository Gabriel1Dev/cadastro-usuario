| Cadastro-Usuario |

Este projeto foi desenvolvido com o objetivo de praticar a construção de uma API REST em Java, aplicando o padrão CRUD (Create, Read, Update, Delete)
com o Spring Boot.

Tecnologias utilizadas:

- Java
- Spring Boot
- H2 Database
- Lombok
- Maven

Funcionalidade:

O programa expõe uma API para o cadastro de usuários, permitindo criar, listar, atualizar e excluir registros (CRUD completo)
através do Spring Web e Spring Data JPA. Os dados são persistidos em um banco de dados H2, que roda em memória durante a 
execução da aplicação. Por ser um projeto de estudo, ele possui limitações:os dados não são mantidos entre 
execuções (o banco é reiniciado toda vez que a aplicação é encerrada).
